## اصول مستندسازی

این پروژه از این اصول پیروی می‌کنه:

1. **دو زبانه** — فارسی (توضیحات) + انگلیسی (کد و اصطلاحات فنی)
2. **مسیر واضح** — هر مستند مخاطب مشخصی داره
3. **کد نمونه** — هر مفهوم با مثال کد همراهه
4. **لینک متقابل** — مستندات به همدیگه ارجاع می‌دن
5. **به‌روزرسانی مداوم** — هر تغییر معماری، مستند می‌شه

## مشارکت در مستندات

اگه می‌خوای مستندات رو بهبود بدی:

1. **آپدیت مستقیم** — اگه تغییر کوچیکه
2. **گزارش جدید** — اگه تغییر بزرگه، به `reports/` اضافه کن
3. **قواعد markdown:**
   - از `##` برای بخش‌ها استفاده کن
   - code blocks رو با زبان مشخص کن (` ```python `)
   - جدول‌ها رو با `|` بساز
