# 0029. Multi-Tenant State for Bots

**Status:** Accepted
**Date:** 2026-10-19
**Deciders:** Hossein, Di Darya, Di Ferdows

## Context
ربات‌های معاملاتی مثل Bear Hunter به ازای هر کاربر یک وضعیت (State) جداگانه دارند که در مسیر `backend/data/bots/{bot_slug}/users/{user_id}.json` ذخیره می‌شود. با اضافه شدن چند کاربر، سوالات مهمی در مورد محدودیت‌ها و منابع (Resource Limits) پیش می‌آید.

## Decision
- **State جداگانه:** هر کاربر دارای سرمایه، تاریخچه ترید و محدودیت‌های مستقل خود است (کاملاً Multi-Tenant).
- **محدودیت‌های سفارش (Per User):** سقف سفارش (per_order_limit) و حجم روزانه (daily_volume_limit) برای **هر کاربر** به صورت جداگانه اعمال می‌شود. (یعنی اگر ۱۰ کاربر باشند، هر کدام می‌توانند تا سقف مجاز خود سفارش ثبت کنند).
- **Kill Switch (سراسری):** در صورت بروز خطای بحرانی در صرافی یا بازار، مدیر سیستم می‌تواند ربات را برای **تمام کاربران** به صورت یکجا متوقف کند.
- **شروع سرمایه:** سرمایه پیش‌فرض هر کاربر جدید در Paper Mode برابر 5,000,000 تومان خواهد بود.

## Consequences
- **Positive:** جداسازی کامل ریسک کاربران، امکان شخصی‌سازی سرمایه برای هر کاربر.
- **Negative:** نیاز به مصرف حافظه بیشتر روی سرور برای نگهداری فایل‌های state متعدد.
