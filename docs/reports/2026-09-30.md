## 🐛 باگ‌های مهمی که حل شد

### ۱. Prefix تکراری `/v1/v1`
`router.py` و `bot.py` هر دو `/v1` داشتن → حل با حذف از sub-router.

### ۲. Wallex دابل‌کانت فریز شده‌ها
Wallex فریز شده‌ها رو توی `locked` **و** `available` نشون می‌داد. با تست عملی تأیید شد که باید از `available` استفاده کنیم.

### ۳. Schema Conflict در Pydantic
دو تا `PortfolioResponse` توی `schemas.py` بود که دومی اولی رو override می‌کرد → با حذف نسخه قدیمی حل شد.

### ۴. `client.get_market()` اشتباه
Wallex پارامتر `symbol` query رو پشتیبانی نمی‌کرد و همیشه همه مارکت‌ها رو برمی‌گردوند → فیلتر سمت کلاینت اضافه شد.

### ۵. `last_price` توی `Market` entity
`map_market` قیمت رو درست استخراج می‌کرد ولی `MarketOut` فیلدش رو نداشت → property اضافه شد.

### ۶. Next.js API Client
`api.getPortfolio()` صدا زده می‌شد ولی `api` فقط یه axios instance بود → کل `lib/api.ts` بازنویسی شد.

### ۷. GRAM فریز شده
بعد از cancel کردن سفارش، GRAM به available برنگشت چون **دابل‌کانت** بوده. Wallex UI هم ۱۲.۸۹ نشون داد (نه ۲۵.۷۸).

### ۸. Next.js rewrites
مسیر `/api/backend/*` → `http://127.0.0.1:8000/*` باعث CORS-free communication شد.

## 💡 درس‌های امروز

1. **Pydantic schema conflicts خیلی گمراه‌کننده‌ست** — Duplicate class به‌راحتی دیباگ رو سخت می‌کنه
2. **Wallex فریز شده‌ها رو دابل‌کانت می‌کنه** — باید از `available` استفاده کرد
3. **uv خیلی سریع‌تر از pip/poetry است** — تجربه‌ی کار روزانه بهتر
4. **Next.js rewrites** یه راه تمیز برای دور زدن CORS
5. **Decimal برای پول** حیاتیه — float error غیرقابل قبوله
6. **type-safe API client** جلوی خیلی از باگ‌ها رو می‌گیره
7. **ruff + mypy** ترکیب قوی برای کیفیت کد پایتون
8. **معماری DDD** درست بود ولی نیاز به انضباط داره
