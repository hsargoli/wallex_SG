## 🎯 درس‌های آموخته

1. **sازماندهی مجدد ≠ حذف.** می‌تونیم بدون پاک کردن چیزی، همه‌چیز رو مرتب کنیم.

2. **`git mv` تاریخچه رو حفظ می‌کنه.** اگه فایل رو با `mv` معمولی جابه‌جا کنیم و `git add` کنیم، git rename رو تشخیص میده ولی مسیر قدیمی می‌مونه. `git mv` بهتره.

3. **Dry-run قبل از اجرا ضروریه.** قبل از انتقال واقعی، ساختار رو نشون دادیم و فراموشی‌ها رو گرفتیم.

4. **چک cross-import ضروریه.** اگه یه اسکریپت از اسکریپت دیگه import می‌کرد و انتقال می‌دادیم، همه چیز می‌شکست.

5. **پوشه‌های خالی تو گیت نمی‌مونن.** `scripts/debug/` خالی بود، ولی git اون رو نمی‌شناخت — باید دستی حذف می‌شد.
