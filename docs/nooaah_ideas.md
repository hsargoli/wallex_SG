## ❌ ایده‌های رد‌شده

### M1 — Momentum Exit (ratio)
**منطق:** اگه ≥X٪ از N کندل ۱m اخیر قرمز → بفروش.
**نتیجه:** `ratio=0.4` → +۲۰.۵۸٪ (بدتر از baseline).
**چرا رد شد:** خروج اضافه → churn (۳۰ trade به‌جای ۱۹).

### M2 — Momentum Exit (consecutive)
**منطق:** ≥N کندل قرمز پشت‌سرهم → بفروش.
**نتیجه:** `consec=3/4` → +۹٪ و +۸.۷٪. `consec=5` → +۱۹.۸۶٪.
**چرا رد شد:** همه بدتر از baseline.

### M3 — Momentum Exit (cumulative)
**منطق:** مجموع تغییرات N کندل ۱m < آستانه → بفروش.
**نتیجه:** بهترینش `-0.5%` → +۲۳.۵٪ (کمی بدتر).
**چرا رد شد:** نزدیک به baseline ولی چیز جدیدی نداد.

### M4 — Momentum + TP=100 (حذف TP)
**منطق:** TP حذف، فقط momentum تعیین کنه.
**نتیجه:** +۱۴.۵٪ و +۱۱.۶٪.
**چرا رد شد:** خیلی بدتر.

### RF — Regime Filter روی entry
**منطق:** اگه X٪ از ۲۰ کندل اخیر trending_up نبود → وارد نشو.
**نتیجه:** همه آستانه‌ها یا بی‌اثر یا بدتر.
**چرا رد شد:** classifier خودش گمراهه، نسبت‌گیری کمک نمی‌کنه.

### TR — Trailing ATR
**منطق:** SL بیاد بالا با peak - mult×ATR. TP حذف.
**نتیجه:** best (mult=3.0) → +۱۰.۶۵٪.
**چرا رد شد:** بازده نصف شد. Sharpe کمی بهتر، ولی trade-off بد.

### ML1 — LightGBM v1
**منطق:** binary classification روی ۲۲ feature bottom-detection.
**نتیجه:** AUC=۰.۵۳۸ (~تصادفی).
**چرا رد شد:** featureها برای regime مناسب نبودن.

### ML2 — LightGBM v2
**منطق:** ۱۲ feature مخصوص Nooaah، label قوی‌تر (TP=4%, SL=2%, lookahead=48h).
**نتیجه:** AUC=۰.۳۵۹۸ (بدتر از تصادفی). Distribution shift شدید بین train/test.
**چرا رد شد:** داده‌ی ۳۰ روز برای ML کافی نیست. طبق توافق قبلی، ML رها شد.

### A1 — RSI Overbought Filter
**منطق:** اگه RSI > X → وارد نشو.
**نتیجه:** `rsi_max=85/80/75` بی‌اثر. `70/65` بدتر.
**چرا رد شد:** زامبی — RSI تو این معاملات هیچ‌وقت بالای ۷۵ نرفته.
