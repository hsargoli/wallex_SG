## خلاصه

API والکس برای دریافت کندل‌های تاریخی، **۹ resolution** رو در مستنداتش لیست می‌کنه:

```text
1, 5, 15, 30, 60, 240, 480, 720, 1D, 1W
```

ولی **در عمل فقط ۶ تاش کار می‌کنه**:

| resolution | معنی | سقف زمانی | کندل |
|------------|------|-----------|------|
| `1` | ۱ دقیقه | ۱ روز | 1440 |
| `60` | ۱ ساعت | ~۲۹ روز | 695 |
| `240` | ۴ ساعت | ~۸۹ روز | 2135 |
| `480` | ۸ ساعت | ~۱۷۹ روز | 4295 |
| `720` | ۱۲ ساعت | ~۳۶۴ روز | 8757 |
| `1D` | روزانه | ~۲ سال | 730+ |

## Resolutionهای معتبر

### `1` — ۱ دقیقه

- **سقف:** ۱ روز
- **کندل در ۱ روز:** 1439
- **برای:** اسکالپ کوتاه‌مدت
- **محدودیت:** فقط ۲۴ ساعت اخیر

### `60` — ۱ ساعت

- **سقف:** ~۲۹ روز
- **کندل در ۳۰ روز:** 719
- **کندل در ۹۰ روز:** 695 (فقط ۲۹ روز آخر)
- **برای:** backtest میان‌مدت

### `240` — ۴ ساعت

- **سقف:** ~۸۹ روز
- **کندل در ۹۰ روز:** 2159
- **نکته:** برای ۱-۳۰ روز، داده `1h` برمی‌گردونه
- **برای:** backtest میان‌مدت تا بلندمدت

### `480` — ۸ ساعت

- **سقف:** ~۱۷۹ روز
- **کندل در ۱۸۰ روز:** 4319
- **برای:** backtest بلندمدت

### `720` — ۱۲ ساعت

- **سقف:** ~۳۶۴ روز
- **کندل در ۳۶۵ روز:** 8757
- **برای:** backtest یک‌ساله

### `1D` — روزانه

- **سقف:** ~۲ سال (و احتمالاً بیشتر)
- **کندل در ۷۳۰ روز:** 730
- **نکته:** **دقیق‌ترین resolution**
- **برای:** تحلیل بلندمدت و backtest چندساله

## Resolution فریبنده: `15`

**`15` (۱۵ دقیقه) در واقع `1m` برمی‌گردونه!**

### اثبات

| بازه | کندل درخواستی (15m) | کندل واقعی (1m) |
|------|----------------------|------------------|
| ۱ روز | 96 | **1440** |
| ۷ روز | 672 | **10080** |
| ۱۴ روز | 1344 | **20159** |

تعداد کندل‌ها با `1m` یکسانه → والکس `15` رو به `1` نگاشت می‌کنه.

**سقف:** ~۱۹ روز (27279 کندل ۱ دقیقه‌ای)

**⚠️ توصیه:** از `15` استفاده نکن. مستقیم `1` یا `60` استفاده کن.

## نکات مهم

### ۱. والکس بازه درخواستی رو نادیده می‌گیره

برای resolutionهای بزرگ، حتی اگه بازه کوچیک درخواست بدی، والکس **کل بازه موجود** رو برمی‌گردونه.

**مثال:** `240` (4h) با بازه ۱ روز → ۲۴ کندل (داده `1h`)

### ۲. سقف هر resolution تقریباً ۲ برابر resolution بعدیه

```text
1h  → 29 روز
4h  → 89 روز (×3)
8h  → 179 روز (×2)
12h → 364 روز (×2)
```

### ۳. `1D` تنها resolution دقیق

فقط `1D` دقیقاً به بازه درخواستی جواب می‌ده.

### ۴. `15` یه باگه

والکس `15` رو به `1` نگاشت می‌کنه ولی برچسب `15` می‌ذاره. **ازش استفاده نکن.**

## روش اندازه‌گیری

**اسکریپت:** `scripts/tools/measure_api_limits.py`

**داده خام:** `data/api_limits/measurement_YYYYMMDD.json`

**روش:**

1. برای هر resolution (۱۰ تا)
2. برای هر بازه (۱۱ تا: 1d, 2d, 3d, 7d, 14d, 30d, 60d, 90d, 180d, 365d, 730d)
3. یک درخواست به `/v1/udf/history`
4. ثبت: `status_code`, `s`, `candles`, `span_days`
5. مکث ۰.۳ ثانیه بین درخواست‌ها

**داده‌های خام در JSON ذخیره می‌شن — قابل بازبینی.**
