## 📖 استراتژی

اسکن مداوم بازار و شناسایی نمادهای نوسانی — بدون ترید.

**فلسفه:** پیدا کردن نمادهایی که نوسان بالا دارند، برای استفاده به‌عنوان
ورودی به ربات‌های ترید (مثل `scalp_master` و `volatility_hunter`).

---

## ⚙ پارامترها

| پارامتر | مقدار | توضیح |
|---------|-------|-------|
| `timeframe` | 1h | تایم‌فریم پیش‌فرض |
| `available_timeframes` | `["15m", "1h", "4h", "1D"]` | تایم‌فریم‌های مجاز |
| `quote` | TMN | ارز مظنه (تومان) |
| `top_n` | 100 | تعداد نماد برای اسکن |
| `min_score` | 0.0 | حداقل امتیاز نوسان |
| `max_concurrent` | 15 | حداکثر اسکن موازی |
| `scan_interval_sec` | 300 | فاصله‌ی اسکن (۵ دقیقه) |
| `save_results` | True | ذخیره‌ی نتایج |

---

## 🚦 منطق

1. دریافت لیست نمادها از والکس
2. محاسبه‌ی امتیاز نوسان برای هر نماد
3. فیلتر بر اساس `min_score`
4. ذخیره‌ی `top_n` نماد در `state.last_results`
5. خواب `scan_interval_sec` و تکرار

**خروجی:** لیست نمادهای نوسانی — بدون انجام هیچ سفارشی.
