## 📐 الگوی مستند هر ربات

هر فایل مستند این بخش‌ها رو داره:

1. **شناسنامه** — slug, name, version
2. **استراتژی** — منطق کلی
3. **پارامترها** — جدول کامل
4. **منطق ورود** — شرایط دقیق
5. **منطق خروج** — SL/TP/Timeout
6. **تایم‌فریم** — پیشنهادی
7. **نتایج بک‌تست** — جدول‌ها
8. **نقاط قوت/ضعف**
9. **تنظیمات پیشنهادی** — برای بازارهای مختلف
10. **وضعیت Live** — آیا آماده‌ست؟
